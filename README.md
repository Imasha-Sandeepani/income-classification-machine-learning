# Income Classification Using Machine Learning

## Project Overview

This project develops machine learning classification models to predict
whether an individual's annual income exceeds $50K based on demographic,
educational, and employment-related characteristics.

The project uses the Adult Income dataset containing 48,842 records.

## Machine Learning Workflow

- Data exploration and cleaning
- Missing value handling
- Categorical variable encoding
- Feature scaling
- Outlier treatment
- Exploratory Data Analysis (EDA)
- Class balancing
- Train-test splitting
- Model development and evaluation
- Hyperparameter tuning
- Model comparison

## Models

- Logistic Regression
- Random Forest
- Gradient Boosting Classifier

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Academic Context

Developed as a group project for the Statistical and Machine Learning
module (DA2111) at the University of Moratuwa.
